# 标准模板与自动排版

## 选择模板

默认`assets/standard-report.docx`是可编辑的标准Word模板。它抽取数模参考模板的版式，清除了原论文正文、批注式指导语、图像和身份信息。它没有固定的八章结构，不要求填写数模内容。来源及有意调整见[模板来源](template-provenance.md)。

当前任务书、用户指定模板优先。`--template`只提取指定DOCX的样式、页面及页眉页脚，清空正文再填充内容，**不是对既有报告就地排版**。不要把用户手工修改的完整报告当输入模板后期望正文被保留。自定义模板必须提供所用的Title、Normal、Heading 1—6、Caption、Code、Table Text等相应样式；只使用普通段落时不要求未用到的样式。模板中的页眉页脚应事先检查，避免携带旧身份或标题。

## 使用

以下命令在技能目录执行，各条为一行。依赖Python 3.10+和python-docx；依赖安装到当前任务允许的环境，不修改无关全局环境。

```powershell
python -m pip install -r requirements.txt
python scripts/format_report.py --input examples/report.json --output output/report.docx
powershell -NoProfile -File scripts/export_word.ps1 -DocumentPath output/report.docx
python scripts/audit_report.py output/report.docx
```

最后两条分别用于Windows Word导出和静态检查。Word会保存传入DOCX并覆盖同名PDF，请先备份。脚本生成成功不代表视觉验收通过；导出后仍须逐页渲染检查。没有Word时可用其他可用转换器，但目录域、字体和页码要另行核对。

默认拒绝覆盖已存在的DOCX；明确使用`--force`才替换，仍禁止覆盖模板、输入或图片（含硬链接）。生成时验证输入并先写临时文件，成功后才替换输出。

指定模板时保留其样式，不自动套用默认字体。只有明确传入`--style-config assets/typography.json`才覆盖模板的相应样式与页面设置；它接受完整配置文件，不接受局部补丁。模板不是新的格式要求，不能覆盖老师明确规定的设置。

## JSON内容格式

根对象包含`blocks`数组。可选字段：`title`、`author`、`subject`、`date`为文字，`metadata`为标签与值均为文字的对象，`cover`、`toc`为布尔值。默认不增加封面页、目录、作者或日期。`cover`只使前面的标题和metadata独占一页，不自动编造姓名栏或身份横线。

| type | 必需字段 | 说明 |
| --- | --- | --- |
| paragraph | text | 普通正文，保留原文空格；不解析Markdown |
| heading | text | level为1—6，默认1；标题文字自己提供，不自动编号 |
| code | text | 原缩进、换行保留在可编辑单列表格；caption可选 |
| table | rows | 二维文字数组，列数一致；第一行作为重复表头；caption可选 |
| image | path | 相对JSON所在目录或绝对路径；caption、width_cm可选；原图字节不修改，图片不超出页面可用区域 |
| page_break | 无 | 显式分页；章节默认不强制换页 |

图表题注由内容作者提供，不自动推断“图几”“表几”，以免插入时生成不符合课程要求的编号。宽表目前等宽分列，长代码与复杂表格需要在Word中核对并手动调整。该格式不支持Markdown富文本、公式、合并单元格或多节页面，不能把复杂数学公式直接写成假LaTeX；有这类需求时使用文档工具补充原生对象。

内容文件只能来自当前任务事实；示例中“尚未执行”不是测试结论。排版程序不会生成实验结果或修改源程序。

## 模板维护

`assets/typography.json`记录可复建的样式参数。仅需再生成标准模板时运行：

```powershell
python scripts/build_template.py --output assets/standard-report.docx --force
python -m unittest discover -s tests -v
```

重建后重新导出并检查模板及示例报告。标准模板包含的示例段落是编辑提示，不是正式报告；生成脚本会清空它们。
