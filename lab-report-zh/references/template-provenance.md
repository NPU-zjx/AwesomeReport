# 模板来源与使用边界

## 原始参考

技能内保留`assets/数学建模国赛标准论文Word模板.doc`原件，SHA256为`82dc4197c4297cc9f166475dd140720c7de74becc4b2d9c350c7d6adbb389a77`。

**仅用格式，忽略内容。**原件提供版式参考，不是内容来源或任务书。不要复制其论文题目、章节、模型、案例、数据、图片、结论、参考文献、AI使用声明或作者身份。不要把原件中的“不要目录”“不超过30页”等要求当作当前任务要求。

原件为旧版`.doc`；核对时可以在副本中用Word转换成`.docx`或PDF，不能修改原件。开发时已将9页原件转换并逐页查看。转换副本的SHA256为`8107c3b6b19b1fe93ddc84a4d22a092817244e7377ad47b07f110758ac92e6f9`；该值用于追溯当时转换，不要求其他Word版本产生相同字节。

## 标准模板

`assets/standard-report.docx`是从原件抽取版式后重新制作的通用模板，不是原文逐页复刻。保留可复用的字体层次和页面尺寸，去掉所有数模内容、图片、复杂浮动对象和旧身份信息。占位文字明确标为样式示例，生成报告时会清空。

| 设置 | 数模参考及标准模板的处理 |
| --- | --- |
| 纸张及页边距 | 原件A4，四边约2.501cm；标准化为21×29.7cm、四边2.5cm |
| 页眉页脚距离 | 原件页眉约1.501cm，页脚两个节约1.799/1.750cm；标准模板统一1.5/1.75cm |
| 正文中文 | 采用原件主要正文的宋体12pt |
| 题目 | 宋体16pt加粗 |
| 一级标题 | 黑体14pt加粗；实验报告按左对齐，不复制数模章名或强制居中 |
| 次级标题 | 宋体12pt加粗 |
| 英文与数字 | 统一Times New Roman；原件部分正文西文字体为宋体，这里按已确认的通用偏好调整 |
| 正文段落 | 首行24pt、1.25倍行距；不复制源文档每处手工空白和硬分页 |
| 表格与题注 | 表格10.5pt、题注12pt；通用数据表采用可见网格，不限定为数模三线表 |
| 代码 | 通用默认9.5pt、单倍行距、可编辑边框表格；这是为报告用途做的调整，非原件12pt代码样式的逐项复刻 |
| 目录及封面 | 由本次任务决定，生成器默认不加；不继承数模“不要目录”规则 |

所有参数可由指定模板或显式配置覆盖。`typography.json`为标准模板的可复建参数，`build_template.py`用于重建。更换参考时重新核对参数和预览，不能只改文件名。
