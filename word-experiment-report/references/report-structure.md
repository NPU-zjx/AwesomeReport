# Report structure and numbering

Use the retained report template as the visual authority, but keep the hierarchy semantically stable:

- 一级：头歌平台实验部分
- 一级：线下实验
  - 二级：线下实验一
  - 二级：线下实验二（如本次任务包含）
- 一级：实验中出现的问题以及解决方案
- 一级：实验总结

If the guide requires separate numbered items inside an offline experiment, number them below that experiment heading. Do not restart the top-level sequence when a second offline experiment is added.

For each question:

1. Question or natural-language requirement.
2. Prompt/model response evidence when model assistance is part of the task.
3. Final SQL or code.
4. Execution result and a short correctness judgment.
5. Result screenshot with a descriptive caption.

For a three-prompt workflow, repeat items 2–5 for A, B, and C, then add a short comparison/conclusion for the question. Keep the image and its caption together where possible.
