# Evidence and asset checklist

## Required report evidence

- The experiment guide or assignment source.
- Environment: operating system, database/client version, and relevant connection/database name.
- Complete verified SQL or code for every required question.
- Execution result for every required question.
- A correctness statement grounded in the result.
- A captioned screenshot for each question/subquestion when screenshots are part of the assignment.
- Problem/error evidence and the corrected result when an initial SQL version failed.

## Source package contents

- Local experiment source SQL, verification SQL, backup and restore files.
- Model-assisted query SQL and the input table/data/question materials needed to reproduce it.
- Platform execution commands or source snippets when the platform does not export a standalone file.
- Execution logs and image sources used in the report.

## Naming

Use stable names such as `Q01_A_prompt.png`, `Q01_A_result.png`, `Q01_A_fixed_result.png`, and `Q01_final.sql`. Keep the question number in both the report caption and the filename. Never replace an error screenshot with the corrected screenshot; retain both when the error explains the solution.
